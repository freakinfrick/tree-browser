# Middle-earth

A **demo tree** for `tb`: every file is real content, so every preview has
something to show: markdown through glow, code and data through bat,
images and PDFs as pictures.

## Regions

| region | what's in it |
|---|---|
| The Shire | ledgers, invitations, a *very* long breakfast plan |
| Bree | the Prancing Pony's guest register |
| Rivendell | council minutes (md + PDF), the library, maps |
| Misty Mountains | a weather report nobody read |
| Moria | the Book of Records, drums (actual `.wav`) |
| Lothlórien | the Mirror's log, still being written |
| Fangorn | entmoot minutes (day 1 of ?) |
| Isengard | production metrics, a memo |
| Rohan / Gondor | infrastructure tickets |
| Mordor | HR, uptime metrics, one volcano |
| Grey Havens | departures |
