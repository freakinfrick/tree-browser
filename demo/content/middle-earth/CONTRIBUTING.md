# Contributing to Middle-earth

Thank you for your interest. The world is, as of this writing, **mostly saved**,
but there is always something.

## Getting started

1. Pick a region. All of them need something.
2. `make breakfast` first. Always.
3. Write in the machine voice: logs, tickets, metrics, configs. If it reads
   like a novel, you have failed. If it reads like a postmortem about a
   Balrog, you are correct.

## Style guide

- **Timestamps** in Shire Reckoning (Third Age years). The calendar is
  loose; nobody will check.
- **Lowercase** for logs, uppercase for the Eye.
- **Dry** where the story is wet. A dragon attack is a "retirement" of an
  "inventory item". A battle is an "incident". A resurrection is a "reboot".
- **Never** explain the joke. The machine does not know it is funny.
- **Provenance + attribution.** Open every document with who filed it, when
  (Third Age), and a ticket ID; cite every quote as `"quote" — Speaker, Place,
  TA-date`.

## Commit conventions

| type | use for |
|---|---|
| `feat` | a new character arrived |
| `fix` | a wall repaired, a gate opened |
| `perf` | a faster horse, a shorter way |
| `refactor` | rewriting the red book (again) |
| `revert` | un-throwing the ring into the sea |
| `docs` | more minutes, more records |
| `chore` | second breakfast |

## Pull requests

- One ring per PR, maximum.
- Do not submit a PR to `mordor`. Mordor is upstream and merges everything
  into fire.
- The Council reviews on a schedule. It may be lunch first.
- Treebeard's reviews take a while. Do not be hasty.

## Code of conduct

1. Do not use the ring.
2. Do not follow the lights in the Dead Marshes.
3. Do not stand on the tables at the Green Dragon.
